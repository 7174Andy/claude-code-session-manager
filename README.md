# Claude Session Panel

A slim Windows window that lists every Claude Code session on this computer, with its state, waiting estimate and recap, and notifies you when one needs you.

It starts minimized to the taskbar and keeps tracking there. Open it from the taskbar to see the list. Closing the window quits the app and stops notifications, so minimize it instead.

- Run: `uv run session-panel`
- Test: `uv run pytest`
